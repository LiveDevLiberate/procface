# ProcFace 国际化

ProcFace 前端和项目文档从 0.1.0 开始提供中文和 English 两种语言。

## 网页

单体网页内置语言资源，不依赖 CDN、字体服务或翻译接口。右上角的 `语言 / Language` 选择器切换界面语言，选择保存在当前浏览器的 `localStorage` 中；首次打开默认使用中文。语言切换不会断开 daemon、停止采样或清除 IndexedDB 历史。

图表指标名、procfs 字段名、API 路径、JSON/TSV 字段名和 Prometheus 名称保持协议定义，不随界面语言改变。设备返回的进程名、错误字段和原始 Trace 值也保持原样，避免改变诊断数据。

## 文档

面向使用者的文档优先在同一文件中提供中文说明和 English 术语。接口与线格式文档保留稳定的字段名和示例；需要完整 English 版本时，文件名使用 `.en.md`，中文版本使用默认 `.md`。新文档应在开头注明语言，避免把机器字段翻译成不稳定的别名。

## 发布

语言资源包含在单体 HTML 中，不产生额外前端请求。修改页面语言资源后必须重新生成内嵌声明和外部签名清单，再更新匹配的 GitHub Release 与 Pages；不能直接修改已签名 HTML。
