# ProcFace 国际化

简体中文 | [English](i18n.en.md)

ProcFace 前端支持简体中文和 English，使用文档提供对应的中英文文件。

## 网页

单体网页内置语言资源，不依赖 CDN、字体服务或翻译接口。右上角的 `语言 / Language` 选择器切换界面语言，选择保存在当前浏览器的 `localStorage` 中；首次打开默认使用中文。存储被禁用时仍可在当前页面切换。语言切换不会断开 daemon、停止 Trace 或清除 IndexedDB 历史。

图表指标名、procfs 字段名、API 路径、JSON/TSV 字段名和 Prometheus 名称保持协议定义，不随界面语言改变。设备返回的进程名、错误字段和原始 Trace 值也保持原样，避免改变诊断数据。

导航、控件、连接帮助、图表分组标题和前端生成的状态提示提供双语。已显示的诊断消息在切换时保留原文；新生成的前端消息使用当前语言。

## 发布

语言资源包含在单体 HTML 中，不产生额外前端请求。修改页面语言资源后必须重新生成内嵌声明和外部签名清单，再更新匹配的 GitHub Release 与 Pages；不能直接修改已签名 HTML。

运行 `node tools/test_frontend_layout.cjs` 验证语言切换、偏好保存、存储禁用降级、连接/Trace/历史保留及原始诊断文本。
