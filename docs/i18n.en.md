# ProcFace internationalization

[简体中文](i18n.md) | English

The frontend supports Simplified Chinese and English. User guides have separate language files, linked below.

## Frontend

Translations are embedded in the standalone HTML, with no CDN, font service or translation API dependency. Use the language selector to switch languages. The selection is stored in browser `localStorage`; the initial default is Chinese. If local storage is unavailable, switching still works for the current page. Switching does not disconnect the daemon, stop Trace or clear IndexedDB history.

Navigation, controls, connection help, chart group titles and frontend-generated status messages are localized. Metric names, procfs fields, API paths, JSON/TSV field names and Prometheus names remain stable. Process names, daemon errors and raw Trace values are diagnostic data and remain unchanged. An already displayed diagnostic message retains its text when switching; newly generated frontend messages use the selected language.

## Release

Language resources are part of the HTML and require no additional frontend requests. After changing them, regenerate the embedded declaration and external signature manifest before updating matching Release and Pages artifacts. Do not edit signed HTML in place.

Run `node tools/test_frontend_layout.cjs` to check switching, preference persistence, restricted storage, connection/Trace/history preservation and raw diagnostic text.
